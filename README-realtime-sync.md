# リアルタイム共有（自動保存・自動共有）を有効にする手順

「保存」「みんなに共有」「最新を取り込む」を自動化するために、Supabase側で1つだけ設定が必要です。

---

## Supabaseで「Realtime」を有効にする

1. ブラウザでSupabaseのプロジェクトを開く（`https://supabase.com/dashboard/project/lzfmcunfwpqtxxzsbodb` など）
2. 左側メニューの **「SQL Editor」** をクリック
3. 右上の **「New query」** をクリック
4. 以下のSQLをそのままコピーして貼り付ける

```sql
alter publication supabase_realtime add table app_state;
```

5. **「Run」** をクリックして実行する
6. 「Success」と表示されれば完了です

**補足**：以前の手順で作った`app_state`テーブル自体はそのまま使います。この1行を追加することで、「誰かがこのテーブルを更新したら、リアルタイムで他の端末に知らせる」という機能が有効になります。

---

## アプリ側の反映

`package.json`に新しい部品（`@supabase/supabase-js`）が追加されているので、パソコン側でも一度だけ次を実行してください（初回のみ）。

```
cd C:\Project\fukubikiya-app
npm install
```

「added ... packages」のような表示が出れば完了です。そのあとは、いつも通りバージョンを上げて配布してください。

```
git add .
git commit -m "保存・共有・取り込みをリアルタイム自動化"
git tag vX.X.X
git push origin main
git push origin vX.X.X
```

---

## 動作確認方法

1. 2台のパソコンにインストールし直したアプリを、両方とも起動しておく
2. 片方のパソコンで、シフトのマスに何か入力する
3. 何も押さずに数秒待つ（自動で保存・共有されます。画面右上あたりの表示が「自動共有しました（時刻）」に変わります）
4. **もう1台のパソコンの画面を見る** → ボタンを押さなくても、自動的に同じ内容が反映されるはずです（「他の端末の更新を反映しました（時刻）」という表示が出ます）

---

## 注意点

- 自動保存・自動共有は、入力してから**4秒後**にまとめて実行されます（1文字ごとに通信しないようにするためです）
- 2人が同時に同じマスを編集した場合、**後から保存された方が優先されます**（今まで通りの「後勝ち」の仕組みです）
- 3つの手動ボタンは、今まで通り残っています。今すぐ強制的に同期したい時や、動作確認用にお使いください
