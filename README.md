# 福引屋シフト管理アプリ（デスクトップ版）セットアップ手順書

このフォルダには、これまで作ってきたHTMLダッシュボードを「インストールして使えるデスクトップアプリ」にするための一式が入っています。

- **Electron**：HTMLアプリをWindows/Macで動く普通のアプリ（.exe など）に変換する仕組み
- **SQLite**：入力したデータをパソコンの中に保存しておく仕組み（保存ボタンで保存されます）
- **GitHub + 自動更新**：新しいバージョンを作ったら、使っている人のアプリが自動で気づいて更新される仕組み

この手順書は、パソコン操作に詳しくない方でも上から順番に進められるように書いています。**上から順番に**進めてください。

---

## 全体の流れ（最初に把握しておくこと）

1. パソコンに「Node.js」という道具をインストールする（1回だけ）
2. パソコンに「Git」という道具をインストールする（1回だけ）
3. GitHubのアカウントを作る（1回だけ）
4. GitHubに「置き場所（リポジトリ）」を作る
5. このフォルダの中身をその置き場所にアップロードする
6. 動作確認（自分のパソコンで試しに起動してみる）
7. 「バージョンタグ」というものを付けてアップロードすると、自動でインストーラーが作られる
8. 完成したインストーラーを、実際に使うパソコンにインストールする
9. 今後、機能を追加したくなったら → バージョン番号を上げてアップロードするだけで、みんなのアプリが自動更新される

---

## ステップ1：Node.js をインストールする

1. ブラウザ（Chromeなど）で **https://nodejs.org/** を開く
2. 画面に大きく出ている2つのボタンのうち、**「LTS」と書かれている方**をクリックしてダウンロードする（LTS = 安定版という意味です。もう片方は選ばないでください）
3. ダウンロードされたファイル（`node-v20.xx.x-x64.msi` のような名前）をダブルクリックして実行する
4. インストーラーが開くので、内容を確認しながら **「Next」→「Next」→…→「Install」→「Finish」** と、基本的にすべて初期設定のまま進めてOKです
5. インストールが終わったら、一度パソコンを再起動してください（念のため）

**確認方法**
1. Windowsの場合：スタートメニューで「コマンドプロンプト」と検索して開く
2. 開いた黒い画面（これを「ターミナル」と呼びます）に、次のように入力して Enter キーを押す

   ```
   node -v
   ```

3. `v20.xx.x` のようにバージョン番号が表示されれば成功です

---

## ステップ2：Git をインストールする

1. ブラウザで **https://git-scm.com/downloads** を開く
2. お使いのパソコンに合わせて（Windowsなら「Windows」）ボタンをクリックしてダウンロードする
3. ダウンロードしたファイルをダブルクリックして実行する
4. 出てくる画面はすべて **「Next」** を押していけばOKです（初期設定のままで問題ありません）。最後に「Install」→「Finish」

**確認方法**
先ほどのコマンドプロンプト（ターミナル）に、次のように入力して Enter

```
git -v
```

`git version 2.xx.x` のように表示されれば成功です。

---

## ステップ3：GitHubのアカウントを作る

1. ブラウザで **https://github.com/** を開く
2. 右上の **「Sign up」** をクリック
3. メールアドレス・パスワード・ユーザー名を入力して、画面の指示に従って登録を進める（メール認証があります）
4. ログインできたら準備完了です

---

## ステップ4：GitHubに置き場所（リポジトリ）を作る

1. GitHubにログインした状態で、右上の **「＋」ボタン → 「New repository」** をクリック
2. 「Repository name」に、好きな名前を入力する（例：`fukubikiya-shift-app`）
3. 「Public」または「Private」を選ぶ（社内だけで使うなら「Private」がおすすめです）
4. 他の項目はそのままでOK。一番下の **「Create repository」** ボタンをクリック
5. 作成されたページに表示されている **URL（例：`https://github.com/あなたの名前/fukubikiya-shift-app.git`）** を控えておく

---

## ステップ5：設定ファイルを書き換える

このフォルダの中の `package.json` というファイルを、メモ帳などのテキストエディタで開いてください（右クリック→「プログラムから開く」→「メモ帳」）。

一番下の方にある、この部分を探します。

```
"publish": [
  {
    "provider": "github",
    "owner": "YOUR_GITHUB_USERNAME",
    "repo": "YOUR_REPOSITORY_NAME"
  }
]
```

- `YOUR_GITHUB_USERNAME` を、あなたのGitHubのユーザー名に書き換える
- `YOUR_REPOSITORY_NAME` を、ステップ4で作ったリポジトリ名（例：`fukubikiya-shift-app`）に書き換える

書き換えたら、上書き保存してください。

---

## ステップ6：このフォルダをGitHubにアップロードする

1. このフォルダ（`fukubikiya-app` フォルダ）を、パソコンのわかりやすい場所（例：デスクトップ）に置く
2. コマンドプロンプト（ターミナル）を開く
3. 次のコマンドを1行ずつ入力し、その都度Enterキーを押していきます（`cd` の後ろは実際にフォルダを置いた場所に合わせてください）

   ```
   cd Desktop/fukubikiya-app
   git init
   git add .
   git commit -m "はじめてのアップロード"
   git branch -M main
   git remote add origin https://github.com/あなたの名前/fukubikiya-shift-app.git
   git push -u origin main
   ```

4. 途中でGitHubのユーザー名・パスワードの入力を求められることがあります（パスワードの代わりに「Personal Access Token」の入力が必要な場合があります。その場合はGitHubの `Settings → Developer settings → Personal access tokens` から作成し、そのトークンをパスワード欄に貼り付けてください）

5. GitHubのリポジトリのページを再読み込みして、ファイル一覧が表示されればアップロード成功です

---

## ステップ7：自分のパソコンで動作確認する

1. コマンドプロンプトで、アプリのフォルダに入っていることを確認（`cd Desktop/fukubikiya-app`）
2. 次のコマンドを入力してEnter（これは初回だけ・少し時間がかかります）

   ```
   npm install
   ```

3. 終わったら、次のコマンドで実際にアプリを起動してみます

   ```
   npm start
   ```

4. シフト管理アプリのウィンドウが開けば成功です。ツールバーに「💾 保存」ボタンが表示されているはずです（ブラウザで直接HTMLを開いた時には出ないボタンです）
5. 何か入力して「💾 保存」を押し、一度アプリを閉じてもう一度 `npm start` してみてください。入力内容が残っていれば、SQLiteへの保存もうまく動いています

---

## ステップ8：インストーラーを自動で作る（GitHub Actions）

`.github/workflows/release.yml` というファイルをすでに用意してあります。これは「バージョンタグ」をGitHubにアップロードすると、GitHub側のパソコンが自動でインストーラー（.exeファイル）を作って、Releasesページに公開してくれる仕組みです。

1. まず `package.json` の一番上の方にある `"version": "1.0.0"` を確認します（最初はこのままでOK）
2. コマンドプロンプトで、次のコマンドを1行ずつ入力します

   ```
   git add .
   git commit -m "v1.0.0 公開"
   git tag v1.0.0
   git push origin main
   git push origin v1.0.0
   ```

3. GitHubのリポジトリページ上部の **「Actions」タブ** をクリックすると、今アップロードした内容をもとに自動でビルド（インストーラー作成）が始まっているのが見られます（黄色い丸＝実行中、緑のチェック＝成功、赤い×＝失敗）
4. 成功したら（数分かかります）、リポジトリページの右側にある **「Releases」** をクリックすると、`v1.0.0` という公開ページができていて、そこに `.exe` のインストーラーファイルが添付されています

---

## ステップ9：実際に使うパソコンにインストールする

1. ステップ8で作られたReleasesページを開く
2. 添付ファイルの中の `〇〇Setup〇〇.exe` のようなファイルをクリックしてダウンロード
3. ダウンロードしたファイルをダブルクリックして実行する
4. インストーラーの案内に沿って進める（インストール先フォルダなどを聞かれますが、基本はそのままでOK）
5. インストールが終わると、デスクトップとスタートメニューに「福引屋シフト管理」のアイコンが作られます
6. アイコンをダブルクリックすればアプリが起動します

---

## ステップ10：今後、機能を追加・修正したときの流れ（自動更新）

1. `renderer/index.html` などのファイルを修正する
2. `package.json` の `"version"` を、例えば `"1.0.1"` のように1つ上げる
3. コマンドプロンプトで、フォルダに入った状態で次を実行

   ```
   git add .
   git commit -m "v1.0.1 修正内容の説明"
   git tag v1.0.1
   git push origin main
   git push origin v1.0.1
   ```

4. あとは自動的に：GitHub Actionsがビルド → Releasesに公開 → **すでにインストールされている各パソコンのアプリが起動時に自動でチェックし、新しいバージョンがあればダウンロード → 「今すぐ再起動して更新」のポップアップが出る**、という流れになります
5. スタッフの方は、アプリを開いてポップアップが出たら「今すぐ再起動して更新」を押すだけでOKです

## よくある質問

**Q. 「💾 保存」ボタンを押し忘れたらどうなる？**
A. 入力内容はアプリを閉じるまでは画面上に残っていますが、SQLiteに保存されるのは「💾 保存」を押した時点の内容だけです。こまめに保存ボタンを押す運用にするか、将来的に「入力するたびに自動保存」に変更することもできます（希望があれば対応します）。

**Q. Macでも使える？**
A. `package.json` に Mac用のビルド設定（dmg）も入れてあります。`.github/workflows/release.yml` は現在Windows用のビルドのみ自動化していますが、Macのビルドを自動化したい場合はワークフローに `runs-on: macos-latest` のジョブを追加する形で対応できます。必要であれば追加のお手伝いをします。

**Q. 複数のパソコン・複数の店舗で使うには？**
A. 現在の設計では、SQLiteのデータは**そのパソコンの中だけ**に保存されます（他のパソコンとは共有されません）。複数拠点でリアルタイムに同じデータを見たい場合は、SQLiteではなくオンラインのデータベース（クラウド）に変更する必要があります。必要であれば別途ご相談ください。

**Q. GitHubのリポジトリは他の人に見られる？**
A. ステップ4で「Private」を選んでいれば、招待した人以外には見えません。

## フォルダの中身の説明

```
fukubikiya-app/
├── package.json          … アプリの設定ファイル（名前・バージョン・ビルド方法など）
├── main.js                … アプリの裏側（起動・保存・自動更新の管理）
├── preload.js              … 画面側と裏側を安全につなぐ橋渡し役
├── src/db.js               … SQLiteへの保存・読み込み処理
├── renderer/index.html     … これまで作ってきたシフト管理ダッシュボード本体
├── build/icon.ico          … アプリのアイコン（仮のものが入っています。差し替え可能）
├── .github/workflows/release.yml … GitHub Actionsの自動ビルド設定
└── .gitignore              … アップロードしなくていいファイルの指定
```
